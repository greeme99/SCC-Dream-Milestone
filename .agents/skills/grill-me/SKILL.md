# Grill-Me Alignment Protocol

## Purpose
Prevent wasted coding tokens caused by vague requirements or assumptions.

## Protocol
1. Identify architectural ambiguities, library choices, or UX branching points.
2. Present 2-4 tight, non-leading multiple-choice questions with recommended defaults.
3. Wait for user decision before writing any production code.

# Project Domain Anchor: Dream Milestone
- Target: 서울대학교 대학원생 맞춤형 커리어 코칭 프로그램 지원 시스템.
- Core Flow:
  1. 사전 OT 및 프리세션 (사전 질문/고민 정리, Welcome Call)
  2. 1회차 코칭 (핵심 이슈 탐색 + 작은 행동 설정)
  3. Between Session 1 (Action Experiment 실행)
  4. 2회차 코칭 (실행 경험 -> 자기이해 -> 방향 도출, 기본 과정 종결)
  5. Between Session 2 & 3회차 코칭 (선택 확장: 미래 커리어/삶의 방향 확장)
- Core Tools: 가치찾기, My Story, 커리어 코칭 질문 라이브러리, Action Experiment, 코칭일지(Google Form/DB 연동).
- Source Document: `Dream Milestone-SIG-full-guide.pdf`.

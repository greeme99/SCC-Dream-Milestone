## 4. 용어집 (Glossary)

| 용어 | 정의 |
| :--- | :--- |
| **삼코동 (SCC)** | 삼성코칭동호회(Samsung Coaching Club). 본 프로그램과 코칭 포털의 단독 주관·운영 주체. |
| **Dream Milestone** | 대학생·대학원생이 자기이해(`Strength & Value`)를 바탕으로 Gap을 탐색하고 커리어 이정표(`Milestone`)와 실행계획(`Action Plan`)을 수립하는 5회기 코칭 프로그램. |
| **SHARE 프로토콜** | `Experience on Demand` 원칙 실행 5단계: 동의 확인(Seek) → 맥락 명시(Highlight) → 핵심 1가지 공유(Add) → 선택권 반환(Return) → 행동 연결(Explore). |
| **Action Experiment** | 회기와 회기 사이(Between Session 1~4)에 학생이 진로 가설을 30~90분 내의 작은 행동으로 직접 검증하고 배움을 기록하는 실험. |
| **학생 코드** | 개인정보 보호를 위해 코칭일지 작성 시 학생 실명 대신 사용하는 비식별 고유 코드(예: `DM-2026-014`). |

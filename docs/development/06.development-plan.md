## 1. 구현 목표 및 첫 번째 수직 슬라이스 (First Vertical Slice)

- **구현 목표**: 삼성코칭동호회(SCC) 코치가 데스크톱과 모바일에서 공용 비밀번호로 입장하여 프리세션~5회기 코칭 가이드 열람, 체크포인트 점검, 구글폼 일지/성과평가 제출, 구글드라이브 참조자료 다운로드를 수행할 수 있는 Next.js 웹앱을 **Netlify Free Tier**에 구축한다.
- **첫 번째 수직 슬라이스 (Phase 1 완료 기준)**:
  `SCR-001`(`/login` 북극성 여정 랜딩 + `POST /api/login` 쿠키 발급) → `middleware.ts` 보호 라우트 통과 → `SCR-002`(`/overview` 앱 셸 + 3대 탭 사이드바 + 라이트/다크 테마 전환) 엔드투엔드 동작 확인.

## 5. 보안, 개인정보, 운영, 백업 및 롤백 계획

1. **보안 및 인증 제어 (`NFR-004`)**:
   - `COACH_SHARED_PASSWORD`와 `SESSION_HMAC_SECRET`은 Netlify Environment Variables(서버 전용)에만 등록하고 `NEXT_PUBLIC_` 접두사를 절대 사용하지 않는다.
   - `netlify.toml` 및 Next.js 헤더에 `X-Robots-Tag: noindex, nofollow`를 설정하여 외부 검색엔진 노출을 차단한다.
2. **개인정보 비보관 원칙 (`NFR-006`)**:
   - 웹앱 자체는 어떠한 학생 개인식별정보(PII)도 수집·저장하지 않으며, 모든 코칭일지와 성과평가는 삼성코칭동호회(SCC) 운영진 계정의 Google Forms로만 수집된다.
3. **배포, 백업 및 즉시 롤백 (Rollback)**:
   - 모든 가이드북 콘텐츠(`src/data/*.ts`)는 Git 저장소에 버전 관리되므로 코드 자체가 영구 백업본이다.
   - 배포 장애 발생 시 Netlify Deploys 대시보드의 **One-Click Publish Deploy (이전 정상 빌드로 즉시 롤백)** 기능을 통해 1분 이내 복구한다.
   - 공용 비밀번호 유출 시 Netlify 환경변수 `COACH_SHARED_PASSWORD`와 `SESSION_HMAC_SECRET`을 변경하고 재배포하여 기존 쿠키를 일괄 무효화한다.

## 7. 바이브 코딩 구현 프롬프트 계약 (Reusable Vibe-Coding Prompt Contract)

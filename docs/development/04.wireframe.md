## 1. 공통 앱 셸 및 반응형·접근성 규격 (`FN-002`, `FN-003`)

- **브레이크포인트**:
  - Desktop (`≥ 1024px`): 고정 상단바(`64px`) + 좌측 고정 사이드바(`272px`) + 우측 메인 컨테이너(`max-width: 1120px`).
  - Tablet / Mobile (`< 1024px`): 상단바 좌측 햄버거 버튼(`☰`, `aria-expanded`) 클릭 시 좌측 슬라이드 오버레이 드로어(`280px`) 노출 + 배경 딤 처리.
- **키보드 및 포커스**:
  - 모든 페이지 최상단에 `본문으로 건너뛰기`(`#main-content`) 스킵 링크 제공.
  - 회기 내 5단계 탭(`role="tablist"`)은 `ArrowLeft` / `ArrowRight` / `Home` / `End` 키로 탐색 가능.
  - 모바일 드로어 오픈 시 포커스 트랩 적용, `Escape` 입력 시 드로어 닫힘 및 햄버거 버튼으로 포커스 복귀.
- **줌 및 고배율 (`200% Zoom`)**: 고정 높이(`height`) 대신 `min-height`와 `flex-wrap`을 사용하여 200% 확대 시에도 텍스트 잘림이 없도록 구성.

## 2. `SCR-001`: 랜딩 및 코치 로그인 화면 (`/login`)

- **화면 목적**: 삼성코칭동호회(SCC) Dream Milestone 프로그램 비전을 제시하고 공용 비밀번호로 코치 인증을 수행한다 (`FN-001`, `FN-003`).
- **주요 액션 (Primary Action)**: 공용 비밀번호 입력 후 `[입장하기]` 제출 (`API-001`).

```text
+---------------------------------------------------------------------------------------+
| [삼코동 로고] | 삼코동 코칭 포털                                     [테마 전환 ☀/🌙] |
+---------------------------------------------------------------------------------------+
|  (Pill) 삼코동 · 고객 주도형 다회기 코칭        +-----------------------------------+ |
|                                                 | 삼코동 코칭 포털에 오신 것을      | |
|  더 나은 내일로 향하는                          | 환영합니다                        | |
|  코칭 가이드 (Electric Royal Blue)              | 코치 전용 공간 접속하기           | |
|                                                 |                                   | |
|  삼코동과 함께 걷는 코칭의 길.                  | 공용 비밀번호를 입력해 주세요     | |
|  프리세션의 첫 대화부터 5회기 Move Forward까지  | [ ******************          ]   | |
|  학생이 스스로 방향을 찾아가는 여정을 돕습니다. | [ (오류 시 경고 배너 표시)    ]   | |
|                                                 | [        입장하기 (Primary)   ]   | |
|  함께, 더 멀리 — 당신의 여정을 응원합니다       | 코치 전용 공간 · 운영진 문의      | |
|                                                 +-----------------------------------+ |
+---------------------------------------------------------------------------------------+
|  [산길 & 북극성 여정 일러스트 SVG: 프리세션 🚩 -> 1~4회기 🚩 -> 5회기 🚩 -> ★ 북극성] |
+---------------------------------------------------------------------------------------+
|  준비하고, 대화하고, 성찰합니다                                                       |
|  +-------------------------+ +-------------------------+ +-------------------------+  |
|  | (1) 코칭 전, 준비       | | (2) 회기와 회기 사이    | | (3) 마치며, 성찰        |  |
|  | 회기별 목적·질문·시간   | | 코칭일지 기록 및 학생의 | | 성과평가와 커리어 맵    |  |
|  | 흐름을 미리 살핍니다.   | | 작은 행동 실험(Action)  | | 통합으로 다음 걸음 설계 |  |
|  +-------------------------+ +-------------------------+ +-------------------------+  |
+---------------------------------------------------------------------------------------+
|  “좋은 질문이 좋은 대화를 만들고, 좋은 대화가 더 나은 변화를 만듭니다.” — 삼코동      |
+---------------------------------------------------------------------------------------+
```

- **상태별 UI (States)**:
  - **Idle**: 비밀번호 입력창 빈 상태, 버튼 활성화.
  - **Loading**: 버튼 텍스트 `"입장 확인 중..."`, `disabled`, 입력창 비활성화.
  - **Error / Denied (401)**: 입력창 테두리 `var(--color-danger)`, 하단 `role="alert"`에 `"비밀번호가 일치하지 않습니다. 삼성코칭동호회(SCC) 운영진에게 문의해 주세요."` 노출.
  - **Success (200)**: `/overview`로 즉시 라우팅.
- **스크린리더 의도**: `<svg role="img" aria-label="겹겹의 산 사이로 굽은 길이 프리세션과 1~5회기 깃발을 지나 산 위의 북극성으로 이어지는 풍경">`, 비밀번호 오류 영역 `aria-live="polite"`.

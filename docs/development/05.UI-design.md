## 2. 듀얼 테마 컬러 토큰 시스템 (`[data-theme="light" | "dark"]`)

순색(`#ff0000`, `#0000ff`, `#00ff00`) 및 하드코딩 헥사코드 직접 사용을 금지하고 반드시 아래 CSS 변수를 사용한다.

| 토큰명 | Light Theme (`[data-theme="light"]`, 기본) | Dark Theme (`[data-theme="dark"]`) | 용도 및 접근성 대비 |
| :--- | :--- | :--- | :--- |
| `--color-bg-base` | `#f8fafc` (Slate 50) | `#0f172a` (Slate 900) | 앱 전체 캔버스 배경 |
| `--color-bg-surface` | `#ffffff` (Pure White) | `#1e293b` (Slate 800) | 메인 카드, 사이드바, 로그인 패널 배경 |
| `--color-bg-subtle` | `#f1f5f9` (Slate 100) | `#334155` (Slate 700) | 서브 컨테이너, 비활성 탭, Between Session 카드 |
| `--color-bg-hover` | `#e2e8f0` (Slate 200) | `#475569` (Slate 600) | 행/버튼 호버 표면 |
| `--color-primary` | `#0066ff` (Electric Royal Blue) | `#6366f1` (Vibrant Indigo) | 주요 CTA 버튼, 강조 텍스트, 활성 탭 인디케이터 |
| `--color-primary-hover` | `#0052cc` (Deep Royal Blue) | `#4f46e5` (Deep Indigo) | 주요 버튼 호버 및 활성 사이드바 텍스트 |
| `--color-primary-light` | `#e0edff` (Soft Blue Tint) | `rgba(99, 102, 241, 0.2)` | 활성 사이드바 배경, 아이브로우 Pill 배지 배경 |
| `--color-text-main` | `#0f172a` (Slate 900) | `#f8fafc` (Slate 50) | 페이지/카드 제목 (명도 대비 > 15:1) |

| `--color-brand-star` | `#f8b62d` (삼코동 스타 골드) | `#f8b62d` (삼코동 스타 골드) | `/login` 여정 일러스트의 북극성 심볼 전용 |
| `--color-border` | `#f1f5f9` | `#334155` | 카드 내부 약한 경계선 |
| `--color-border-strong` | `#e2e8f0` | `#475569` | 테이블·입력창·구분선 보더 |
| `--color-success` / `bg` | `#10b981` / `rgba(16,185,129,0.12)` | 동일 | 완료 배지, 클립보드 복사 토스트 |

| `--color-danger` / `bg` | `#ef4444` / `rgba(239,68,68,0.12)` | 동일 | 로그인 오류 메시지, 윤리·안전 경고 |

## 3. 타이포그래피 및 공간·곡률 스케일

### 3.1 폰트 패밀리
- **Primary Sans**: `'Pretendard'`, `'Plus Jakarta Sans'`, `'Inter'`, `-apple-system`, `BlinkMacSystemFont`, `sans-serif`
- **Monospace**: `'JetBrains Mono'`, `'Fira Code'`, `monospace`
- **줄바꿈 규칙**: 한국어 제목과 본문 단락에는 `word-break: keep-all`을 기본 적용하여 어절 단위 가독성을 보장한다.

### 3.2 타이포그래피 계층 토큰

| 토큰명 | 크기 | 굵기 (Weight) | 줄높이 | 적용 대상 |
| :--- | :--- | :---: | :---: | :--- |
| `--font-h1` | `1.875rem` (30px) | `700` (Bold) | `1.25` | 회기 메인 타이틀, 대시보드 제목 |
| `--font-h2` | `1.375rem` (22px) | `600` (SemiBold) | `1.3` | 섹션 헤더, 로그인 카드 타이틀 |
| `--font-h3` | `1.125rem` (18px) | `600` (SemiBold) | `1.4` | 단계 탭 패널 타이틀, 서브 카드 헤더 |
| `--font-body` | `0.938rem` (15px) | `400` (Regular) | `1.6` | 코칭 질문, 가이드 본문, 테이블 셀 |
| `--font-caption` | `0.813rem` (13px) | `500` (Medium) | `1.4` | 시간 배지(`10분`), 단계 라벨, 보조 캡션 |

### 3.3 간격(Spacing) 및 곡률(Radius) 토큰
- **Spacing**: `4px`(`xs`), `8px`(`sm`), `16px`(`md`), `24px`(`lg`), `32px`(`xl`), `48px`(`2xl`).
- **Radius**:
  - `--radius-sm`: `6px` (테이블 내부 태그, 체크박스)
  - `--radius-md`: `10px` (사이드바 활성 메뉴, 입력창, 일반 버튼)
  - `--radius-lg`: `18px` (모든 메인 콘텐츠 카드, 로그인 카드, 모달)
  - `--radius-pill`: `9999px` (아이브로우 배지, 단계 탭 버튼, 외부 구글폼 CTA 버튼)

## 4. 핵심 UI 컴포넌트 규격

### 4.1 사이드바 내비게이션 (`FN-002`)
- **활성 항목**: 배경 `var(--color-primary-light)`, 텍스트 `var(--color-primary-hover)`, 굵기 `600`, 곡률 `10px`, 그림자 없음 (`DESIGN.md` DEC-014/DEC-028 준수).
- **비활성 항목**: 텍스트 `var(--color-text-muted)`, 호버 시 배경 `var(--color-bg-subtle)`, 텍스트 `var(--color-text-main)`.

### 4.2 회기 5단계 인터랙티브 탭 바 (`FN-006`)
- 컨테이너: `background: var(--color-bg-subtle)`, `padding: 6px`, `border-radius: var(--radius-lg)`, 가로 스크롤 없이 `flex-wrap: wrap` 배치.
- 각 탭 버튼: `1. 도입 (10분)`, `2. 탐색 (15분)`, `3. 심화 (15분)`, `4. 실행설계 (12분)`, `5. 마무리 (8분)`, `Between Session`.
- 활성 탭: `background: var(--color-primary)`, `color: var(--color-text-on-primary)`, `box-shadow: var(--shadow-card)`.

### 4.3 코칭 질문·공감·체크포인트 카드 (`FN-006`, `FN-007`)
- **핵심 코칭 질문 리스트**: 좌측 `4px` 두께의 `var(--color-primary)` 보더와 큰 따옴표 아이콘으로 코치가 현장에서 즉시 읽을 수 있도록 시각적 위계를 높인다.
- **공감 표현 가이드 박스**: `background: var(--color-primary-light)` 바탕에 부드러운 아이콘(`💬 공감 가이드`)을 배치한다.
- **인터랙티브 체크포인트**: 클릭 영역 최소 `44px × 44px` 터치 타겟 확보, 체크 완료 시 취소선 대신 텍스트 강조와 에메랄드 체크 배지(`var(--color-success)`)를 표시한다.

### 4.4 외부 연동 CTA 버튼 (구글폼 3종 & 구글드라이브 5종, `FN-008`, `FN-009`)
- **코칭일지 & 성과평가 구글폼 CTA**: `--radius-pill` (`9999px`), `background: var(--gradient-primary)`, 흰색 텍스트, 우측 상향 화살표 `↗`, 호버 시 `transform: translateY(-2px)` 및 `--shadow-hover` 적용.
- **학생 성과평가 링크 복사 버튼**: `background: var(--color-bg-surface)`, `border: 1px solid var(--color-primary)`, `color: var(--color-primary)`, 클릭 시 토스트 알림.
- **데이터 테이블 정렬 기호 (`DESIGN.md` 섹션 4.3 준수)**: 정렬 가능한 매트릭스/리소스 테이블 열 헤더에는 비활성 정렬 기호 `⇅`(`opacity: 0.35`)와 활성 정렬 기호 `▲` / `▼`(`color: var(--color-primary)`)를 표시한다.

## 5. 정적 디자인 검증 프로토타입 명세 (`ui-prototype/`)

`DEC-001`에 따라 승인된 디자인 토큰과 3대 기능 탭 인터랙션을 즉시 검증할 수 있는 무의존성 정적 프로토타입을 패키지 내에 포함한다.
- **파일 구성**:
  - [ui-prototype/index.html](./ui-prototype/index.html): `/login` 게이트 + 상단바 + 3대 탭 사이드바(`개요`, `코칭모델 [프리세션 + 1~5회기]`, `참조자료`) 마크업
  - [ui-prototype/styles.css](./ui-prototype/styles.css): `DESIGN.md` Light/Dark CSS 변수 및 반응형 스타일시트
  - [ui-prototype/app.js](./ui-prototype/app.js): 픽션 데모 비밀번호 로그인/로그아웃, 회기별 5단계/Between 탭 전환, 체크포인트 `localStorage` 저장/초기화, 테이블 정렬(`⇅`/`▲`/`▼`), 구글폼 연동 및 학생 평가 링크 복사 토스트
- **고지 사항**: 프로토타입은 디자인 및 UX 검증용 산출물이며 모든 샘플 데이터(예: 데모 비밀번호 `scc2026`, 샘플 학생 코드 `DM-2026-001`)는 픽션이다.
